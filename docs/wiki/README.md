# Wiki de Agendia — v0.1.0

El motor de reservas, calendarios y disponibilidad de la plataforma. Define cómo trabajas
y Agendia calcula los huecos, acepta reservas sin errores y avisa a todo el mundo.

Esta wiki tiene **dos niveles**. Empieza por el que encaje con lo que buscas:

| Nivel | Para quién | Contenido |
|---|---|---|
| **[Nivel funcional](funcional.md)** | Cualquier persona | Qué hace Agendia y qué te resuelve, sin tecnicismos y con ejemplos. |
| **[Nivel técnico](tecnico.md)** | Equipo de desarrollo | Arquitectura, dominio, motor de horarios y citas, seguridad, persistencia y pruebas. |

---

- **Versión:** 0.1.0
- **Ámbito:** gestión de citas multi-negocio
- **Stack:** .NET 9 · ASP.NET Core · EF Core 9 · SQL Server
- **Identidad:** externa (servicio Harmony)
